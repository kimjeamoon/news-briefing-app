확산 모델 기반 개념 시각적 반사실 설명 연구

새로운 확산 프레임워크인 C-VCE(Concept-based Visual Counterfactual Explanations)가 발표되었습니다. 이 모델은 분류기를 생성 모델에 직접 통합하여 인간이 해석 가능한 개념을 통해 반사실을 유도하며, 이미지 편집의 현실성과 정확도를 높였습니다.

LLM 신뢰성 평가: 동일 질문 다른 답변 연구

새로운 연구에 따르면 LLM은 동일한 질문이 다르게 표현될 때 답변이 자주 변경되어 정확도만으로는 신뢰성을 완전히 평가하기 어렵습니다. 모델이 동일한 질문의 다른 표현에 대해 정답과 오답을 오가는 경우가 23%에 달했으며, 이는 근본적인 지식이 존재하지만 일관되게 검색되지 않음을 시사합니다.

출처: arXiv cs.AI

LLM 평가 및 에이전트 시스템 메모리 관리 연구

확장 가능한 LLM 평가를 위한 'Codifying the Judge: Scalable Evaluation via Program Distillation'과 LLM 에이전트의 효율적인 장기 기억 관리를 위한 'SF-AMS: Strategic Forgetting for Structured Memory in LLM Agent' 연구가 발표되었습니다. 이들은 각각 평가의 투명성과 효율성을 높이고, 에이전트의 다단계 추론 성능을 향상시키는 데 기여합니다.

출처: arXiv cs.AI · arXiv cs.AI

소형 언어 모델의 지속 학습 및 의료 진단 에이전트 워크플로우 연구

소형 언어 모델(SLM)의 지속적인 학습을 위한 'MIITA' 프레임워크와 의료 진단 에이전트 워크플로우 설계에 대한 연구가 진행되었습니다. MIITA는 제한된 저장 공간에서 파라미터 업데이트 없이 지식 유지를 가능하게 하며, DeepLens Diagnosis Agent는 소형 추론 모델이 정교한 워크플로우 설계를 통해 선도적인 LLM과 경쟁할 수 있음을 보여주었습니다.
